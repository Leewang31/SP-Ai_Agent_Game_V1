## 5. 스크립트 / 씬 구조

| 파일 | 역할 |
|------|------|
| `PlayerController.gd` | 이동, Shift 달리기, 우클릭 공격, 스페이스 점프 |
| `BotController.gd` | 자유 이동 AI, 점프, 피격 처리(쓰러짐 + 2초 후 제거) |
| `MapGenerator.gd` | 50×50 바닥 + 경계 벽 생성 |
| `GameManager.gd` | 봇 10마리 스폰 |

## 6. 완료 기준

- [ ] Godot에서 실행 시 오류 없이 씬이 열릴 것
- [ ] 플레이어 WASD 이동 가능
- [ ] Shift 달리기(×1.8) 동작
- [ ] 스페이스바 점프 동작
- [ ] 봇 10마리 맵 내 자율 이동
- [ ] 플레이어 / 봇 기본 이동 속도 완전 동일
- [ ] 우클릭 시 2m 이내 봇 쓰러짐 → 2초 후 사라짐

## 7. 확정된 수치 기본값

| 항목 | 값 |
|------|----|
| 맵 크기 | 50×50 m |
| 경계 벽 높이 | 3 m |

| 쓰러진 후 제거 시간 | 2초 |
| 봇 스폰 수 | 10마리 |
